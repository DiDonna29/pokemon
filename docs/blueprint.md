# **App Name**: PokeNexus

## Core Features:

- Infinite Dex Grid: A high-performance responsive grid featuring infinite scroll to browse all Pokémon species seamlessly via PokeAPI integration.
- Intelligent Discovery Tool: An AI-powered search tool that helps users identify Pokémon based on natural language descriptions or combat attributes.
- Caught Status Tracker: Persistence layer allowing users to toggle and save which Pokémon they have captured in a personal digital collection.
- Evolution Graph Viewer: Dynamic visualization of evolution chains requiring nested API calls to display complex species transformations.
- Multi-criteria Filtering Drawer: Advanced sidebar navigation for filtering by primary type, weight class, height, and statistical rankings.
- Tabbed Pokemon Dossier: Deep-dive detail views featuring animated base stats, flavor text, and gender-specific sprite variations.
- Global Alphabetical Sorting: Real-time sorting functionality for the main library, supporting A-Z, Z-A, and numerical ordering by Dex ID.

## Style Guidelines:

- A sophisticated dark-mode aesthetic with a Primary Deep Navy (#0F172A) and a vibrant Primary Accenting Electric Yellow (#FACC15) for high-energy call-to-actions.
- Accent: Analogous Indigo (#6366F1) used for high-contrast badge details and specialized type-based highlighting.
- A refined pairing of 'Space Grotesk' for tech-centric headlines and 'Inter' for highly legible body copy and data statistics.
- Minimalist vector icons with fine 1px strokes to represent statistics (attack, defense, speed) and habitat categories.
- Modular card-based layout inspired by high-end collectible trading cards with semi-transparent glassmorphism backgrounds.
- Micro-interactions including card tilt on hover and smooth staggered transitions for list item entrance animations.
