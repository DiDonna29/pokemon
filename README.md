# ⚡ PokeNexus | Ultimate Pokédex Companion

**PokeNexus** es una aplicación de vanguardia diseñada para entrenadores Pokémon que buscan una experiencia digital inmersiva. Construida con **Next.js 15**, **Genkit** y la **PokeAPI**, ofrece herramientas avanzadas de descubrimiento, combate y entretenimiento.

## 🚀 Inicio Rápido

Este proyecto es compatible con `npm`, `yarn` y `pnpm`.

### Instalación de dependencias:
```bash
npm install
# o
yarn install
# o
pnpm install
```

### Ejecución en desarrollo:
```bash
npm run dev
```

### Construcción para producción:
```bash
npm run build
npm start
```

## ✨ Características Principales

- 🔍 **Búsqueda Inteligente:** Encuentra cualquier Pokémon por nombre, ID o tipo.
- 🤖 **Descubrimiento IA (Genkit):** Utiliza lenguaje natural para encontrar Pokémon (ej: "un tipo fuego rápido").
- ⚖️ **Filtros Avanzados:** Clasifica por clase de peso, altura y tipos elementales.
- 🛡️ **Campo de Batalla:** Simula enfrentamientos épicos entre dos especies analizando sus estadísticas.
- 🎮 **Quiz "¿Quién es ese Pokémon?":** Pon a prueba tus conocimientos con un sistema de siluetas, pistas y revelación con suspenso.
- 🎒 **Colección Personal:** Marca tus capturas y filtra tu Pokedex para ver solo tu equipo.
- 🌓 **Diseño Adaptativo:** Estilo *Glassmorphism* premium con soporte total para modo claro y oscuro.

## 🛠️ Stack Tecnológico

- **Frontend:** Next.js 15 (App Router), React 19, Tailwind CSS.
- **UI Components:** Shadcn/UI, Framer Motion (Animaciones), Lucide React (Iconos).
- **IA:** Genkit + Google Gemini (Modelos generativos).
- **API:** PokeAPI (Datos en tiempo real).

Para una guía técnica más profunda, consulta el archivo `PROJECT_DETAILS.md`.
